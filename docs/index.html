EffOff

An R package for Automated Vegetation Analysis & Trend Detection using Google Earth Engine to determine the Efficacy of Offset Forestry (Eff-Off) under the CAMPA program in India

Note: This package is intended to accompany a forthcoming scientific publication (details TBD) and serves as a tool for quick visual analysis. It will not be frequently updated and may contain errors. Users are solely responsible for verifying the code, results, and their use of the data. Any study utilizing this tool should ground-truth the results.

1. Data Extraction

Under the Hood:

  • Collection Filtering: Queries the GEE catalog for Landsat 5, 7, and 8 collections intersecting your Region of Interest (ROI) and time range.
  • Cloud Masking: Applies the QA_PIXEL bitmask to remove clouds and shadows for every image.
  • Harmonization: Applies scaling factors to surface reflectance bands and computes EVI using the standard formula: 2.5 * ((NIR - Red) / (NIR + 6 * Red - 7.5 * Blue + 1)). 
# Install the package from GitHub
    devtools::install_github("username/EffOff")

# Load the EffOff package
    library(EffOff)

# Set a Working Directory for the project and exports
    setwd("path/to/your/project")

# Load your region of interest (.shp, .kml)
    roi <- st_read("project_area.shp")

# Extract harmonized EVI (1990-2024)
# Automatically handles Landsat 5, 7, and 8 harmonization
# You may be asked to allow Tidyverse to access your Google Earth Engine and Drive accounts using your browser
    evi_data <- extract_evi(roi, start_year = 1990, end_year = 2024)

Key Dependencies: rgee for GEE interface. Please ensure proper installation and authentication of rgee and its dependencies.

2. Data Processing

Under the Hood:

  • Sensor Prioritization: For months with overlapping data, it selects pixels using the hierarchy Landsat 8 > Landsat 5 > Landsat 7 to minimize artifacts.
  • Gap Filling: Identifies missing months and imputes values using linear interpolation via zoo::na.approx.
  • Aggregation: Computes annual means (Jan-Dec), dry season means (e.g., Mar-May), and wet season means (e.g., Jun-Oct) using dplyr grouping.
# Clean EVI data, fill gaps in the time series, and calculate seasonal means
# Returns a list containing Annual (AM), Dry Season (ADM), and Wet Season (AWM) means
# wet and dry seasons can be defined by the user
    cleaned_list <- clean_evi_data(evi_data, wet_months = 6:9, dry_months = 2:5)

    annual_means <- cleaned_list$AM
    dry_season_means <- cleaned_list$ADM
    wet_season_means <- cleaned_list$AWM

Context: Multi-sensor time series often suffer from data gaps and sensor artifacts (e.g., Landsat 7 SLC failure).

Key Dependencies: tidyverse for data manipulation, zoo for interpolation.

3. Statistical Analysis

Under the Hood:

  • BFAST Lite: Decomposes the time series into trend, seasonal, and remainder components to find the single most significant structural break.
  • Shape Selection: Fits 7 distinct shape models (flat, increasing, decreasing, vee, etc.) to the time series and selects the best fit using the Bayesian Information Criterion (BIC).
  • Mann-Kendall: Computes the S-statistic on autocorrelation-corrected data to determine trend significance, and uses Sen's method to estimate the median slope.
# Run comprehensive trend analysis
# annual_means can be replaced with dry_season_means or wet_season_means
    results <- analyze_trends(annual_means)
    str(results)

# Results include:
# - SSF ShapeC'Constrained': The classified trend shape as increasing, decreasing, or flat.
# - SSF Shape_'Unconstrained':  All possible classified trend shapes (including double jump, vee, etc.) 
# - Sen’s slope: The median slope estimator of the monotonic trend in the time series.
# - Tau: Kendall’s tau statistic, measuring the strength and direction of the monotonic association.
# - p-value: The probability of observing the test statistic under the null hypothesis of no monotonic trend.
# - Zc: The standardized Z statistic of the Mann–Kendall test, used to assess statistical significance.
# - Breakpoint_Year: The year of a structural change detected by the BFAST algorithm

Context: Distinguishing genuine ecological recovery from natural variability requires a multi-faceted statistical approach.

Key Dependencies: bfast, ShapeSelectForest, modifiedmk.

4. Visualization

Under the Hood:

  • Spatial Mapping: Generates high-resolution (600 DPI, A4) spatial maps using geom_sf. Automatically exports "Basemap", "Structural", and "Statistical" panels as transparent PNGs to Results/<Basename>/.
  • Summary Plots: Creates stacked bar charts or histograms to visualize trend distributions. Exports a combined summary plot (A4, 420mm height) to the same results directory.
  • Automated Export: All outputs, including processed data (CSV/GeoJSON) and visualisations, are automatically organized into folders based on the input filename and analysis period (e.g., Results/ROI_1990_2024_AM/). 
# Map the trend shapes
    plot_trend_map(results, variable = "SSF_Shape", title = "Vegetation Trends (1995-2024)", roi_sf = roi)

# Summarize trend distribution (Single Variable)
    plot_trend_summary(results, category_col = "SSF_Shape")
