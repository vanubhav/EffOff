EffOff

An R package for Automated Vegetation Analysis & Trend Detection using Google Earth Engine to determine the Efficacy of Offset Forestry (Eff-Off) under the CAMPA program in India

Note: This package is intended to accompany a forthcoming scientific publication (details TBD) and serves as a tool for quick visual analysis. It will not be frequently updated and may contain errors. Users are solely responsible for verifying the code, results, and their use of the data. Any study utilizing this tool should ground-truth the results.

1. Data Extraction

Under the Hood:

  • Collection Filtering: Queries the GEE catalog for Landsat 5, 7, and 8 collections intersecting your Region of Interest (ROI) and time range.
  • Cloud Masking: Applies the QA_PIXEL bitmask to remove clouds and shadows for every image.
  • Harmonization: Applies scaling factors to surface reflectance bands and computes EVI using the standard formula.
# Install the package from GitHub
    devtools::install_github("username/EffOff")

# Load the EffOff package and set working directory
    library(EffOff)
    setwd("path/to/your/project")

# Load your region of interest (.shp, .kml)
    roi <- st_read("project_area.shp")

# Extract full-history harmonized EVI (defaults: 1990 to present)
# Automatically handles Landsat 5, 7, and 8 harmonization.
# The 'file_name' formats your output folders.
    evi_data <- extract_evi(roi, file_name = "Site_Name_XYZ")

Key Dependencies: rgee for GEE interface.

2. Data Processing

Under the Hood:

  • Sensor Prioritization: For overlapped months, selects pixels using Landsat 8 > Landsat 5 > Landsat 7.
  • Gap Filling: Imputes missing monthly values using linear interpolation via zoo::na.approx.
  • Aggregation: Computes annual, dry season, and wet season means automatically.
# Clean EVI data (removes invalid points, fills gaps, prioritizes sensor)
    cleaned_data <- clean_evi_data(evi_data)

# Compute seasonal means based on custom temporal bounds
    means_list <- calculate_means(cleaned_data, wet_months = 6:9, dry_months = 2:5)

    annual_means <- means_list$AM
    dry_season_means <- means_list$ADM
    wet_season_means <- means_list$AWM

Context: Multi-sensor time series often suffer from data gaps and sensor artifacts.

3. Multi-Period Trend Analysis

Under the Hood:

  • Phase Splitting: Automatically splits project timelines into Pre-Management, Management, Post-Management and Full Intervention spans based on your deployment years.
  • Statistical Battery: Uses dynamically scaling BFAST formulas avoiding sparse constraints, ShapeSelectForest (trajectory shape), and Autocorrelation-corrected modifiedmk tests for temporally rigorous Mann-Kendall evaluations.
  • Spatial Agreement: Computes explicit multi-indicator spatial agreement grids internally mapped across Agreement_Triple to confidently locate definitively positive or negative overlaps ("Both Positive", "All Negative", etc).
# Run comprehensive trend analysis against project timelines
    results_list <- analyze_trends(annual_means, project_start_year = 2005, project_end_year = 2012)
    names(results_list) 
    # Outputs include: "Pre_Management", "Management", "Transitions", "Post_Management"...

# Results per significant pixel include:
# - SSF Shape 'Constrained': Classified shape as strictly increasing, decreasing, or flat.
# - Sen’s slope & Tau statistic: Measuring severity and direction (fully corrected for autocorrelation).
# - Agreement_Tau_Sen & Agreement_Triple: Categorical tracking mapping cross-indicator confirmation.

4. Visualization

Under the Hood:

  • Period-Specific HTML Reports: `visualize()` dynamically renders segmented performance dashboards tracking data specific to every intervention phrase.
  • Custom Mappings: Quickly map structural and categorical agreement metrics directly side-by-side using unified High-DPI transparent PNGs.
# Generate comprehensive HTML reporting suite for all management phases at once
    visualize(results_list)

# Map custom indicators directly for a single timeline phase
    mgmt_sf <- results_list$Management
    plot_trend_map(mgmt_sf, variable = "Agreement_Triple", title = "Full Agreement Between Tau, Sen, and SSF")

# Summarize distributions overall
    plot_trend_summary(mgmt_sf, category_col = "Agreement_Tau_Sen")
